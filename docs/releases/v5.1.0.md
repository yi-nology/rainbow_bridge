# Rainbow Bridge v5.1.0

本版在 v5.0.3 基础上补齐 MinIO 发布快照存储、历史迁移和失败恢复，并修复配置写入后的缓存刷新及 HTTP 内网环境的发布请求 ID。原有 API 地址与前端操作方式保持兼容。

## 新增与修复

- 发布快照可选择 local 或 MinIO。MinIO 原始资源与不可变快照使用不同私有 bucket；资源全部上传并实际回读校验大小、SHA-256 和完整性清单后，才提交可用版本。创建版本仍不自动生效。
- 每个版本持久保存自己的存储定位，支持 local 与 MinIO 历史混合读取；修改全局配置不会重定向旧版本。激活、active/fixed runtime、资源下载、静态 ZIP 及 transfer 生效/指定版本归档统一按版本读取。
- 新增 `release-storage` 运维工具：默认只读盘点，支持明确选择后的 local→MinIO 迁移、验证、迁移定位回退及失败 attempt 补清。迁移保留原文件和版本内容、编号、生效指针、revision、删除历史；缺失历史不会从当前原始资源重建。
- 上传 attempt 独立持久登记；清理与发布共用数据库写协调，检查已提交引用后才能认领并删除自己的前缀。失败可保留 `cleanup_pending`/`unknown`，禁止按年龄盲删历史快照。
- 修复配置创建、更新、删除、导入及迁移后的 scope 详情、列表和 map 缓存失效；不靠关闭 Redis 或等待 TTL 刷新。
- 修复 HTTP 内网环境缺少 `crypto.randomUUID` 时无法生成发布操作请求 ID 的问题；发布操作和备份流程使用兼容的 UUID 生成入口。
- 保留 v5.0.2 的 HTTP 会话显式 `allow_insecure_remote` 开关及 v5.0.3 的 Docker arm64 二进制架构修正。

## 升级与部署

- 新增 `release_storage.type: local|minio`，缺省为 local，旧空存储标记也解释为 local。MinIO 模式必须配置与原始区不同的私有快照 bucket，连接复用 `storage.minio`；运维预建桶，业务请求不建桶，不允许失败回退到 local。
- 升级包含版本定位列及 `release_storage_attempt` 表的增量数据库迁移。升级前保存数据库、原始资源和快照的一致副本，并审核停写窗口；本次发布不会自动更新正在运行的实例或迁移业务历史。
- 先用 `release-storage --config <私有配置> --action plan` 盘点。迁移/回退/补清的执行需要明确实例确认及 snapshot/attempt 选择。快照区禁止自动 TTL 删除；已有 local 历史未全部迁移并验收前，保留原目录和旧卷。
- 旧二进制不识别 MinIO locator。生成原生 MinIO 版本后不能直接降级；迁移而来的版本也只能在旧文件完整校验后显式回退定位，不可随意修改 backend 或恢复旧库丢弃新版本。
- 整实例备份 schema 升至 4，支持旧 schema 1/2/3 包在隔离候选库升级；attempt 运行状态不进入恢复包。完整备份仍只支持单实例 SQLite、本地原始资源、本地快照且全部历史无 MinIO locator、Redis 关闭的部署。PostgreSQL/MinIO 整实例备份未扩展。
- 缓存修复不保证严格线性一致：在途旧读仍可能在失效后回填，至后续失效或 TTL 到期（详情/map 1 小时，列表 30 分钟）。跨进程存储验证不等于全系统 K8s 多副本验收。

配置与权限见 [MinIO 快照部署说明](https://github.com/yi-nology/rainbow_bridge/blob/v5.1.0/deploy/kubernetes/release-snapshots/minio-snapshots.md)，迁移和恢复命令见 [release-storage 使用说明](https://github.com/yi-nology/rainbow_bridge/blob/v5.1.0/cmd/release-storage/README.md)。

## 验证与下载

本轮代码已通过 Go 全仓回归与受影响静态检查、故障/崩溃恢复夹具；独占远程 PostgreSQL、Redis、两只 MinIO 桶验证了十资源完整发布、三份 local 历史迁移和不同工作目录候选进程跨读。原有业务范围元数据前后一致，测试资源已清理。现有运行部署尚未更新。

应用包覆盖 Linux amd64/arm64、macOS amd64/arm64、Windows amd64；内含嵌入前端的 app、`admin-password-reset`、`backup-restore`、`release-storage`、工具说明、示例配置、API 与部署文档。另有独立 `frontend.zip`/`frontend.tar.gz`、`QUICKSTART.md`、本发布说明与 `SHA256SUMS.txt`。默认服务路径 `/rainbow-bridge`，包内配置为回环地址 SQLite 体验环境；对外部署须自行配置 HTTPS、会话来源和实际存储。
