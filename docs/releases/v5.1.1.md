# Rainbow Bridge v5.1.1

本版在 v5.1.0 基础上新增 PostgreSQL、MinIO、Redis 与 Kubernetes 部署下的手动全量备份和恢复，以及可在业务停服期间继续使用的网页管理入口。原有 SQLite 单实例模式继续保留；分布式模式需要按部署说明显式启用，升级镜像不会自动切换现有数据库或认证存储。

## 新增与修复

- 网页支持备份方案核对、手动创建全量备份、列表与完整性核验、恢复预览和确认、进度及任务历史。中断后可根据服务端允许的动作继续执行或安全恢复原服务；关闭浏览器不会取消后台任务。
- 备份进入明确的停服维护窗口，等待业务 Pod 退出后读取一致数据；包含业务配置、资源、发布快照、范围及发布历史。对象和逻辑数据校验通过后才发布可用备份，半包不会成为恢复点。
- 恢复写入新数据库和新 MinIO 桶，逐项校验后切换并核对业务就绪，保留原数据库和对象。阶段、执行者及资源归属持久化；拒绝旧执行者未停止时的接管，开放新写入后拒绝直接回退，避免丢失新数据。
- 新增独立 `maintenance-console` 和同源 `maintenance-gateway`：业务 Pod 停服时，静态页面、管理员登录及任务查询仍可用；业务 API 返回明确的维护状态。
- 新分布式网页模式将管理员认证显式迁入独立控制库，恢复业务数据不会回退当前密码。恢复成功后旧普通会话失效，需重新登录；任务限定的只读结果 Cookie 可短时查看完成结果，不授予其他操作权限。
- 固定 Kubernetes Job 执行备份恢复，持久请求与 outbox 支持幂等受理和重启接续；浏览器不能指定执行镜像、命令、数据库连接或挂载。接口仅返回安全任务视图和可用动作。
- 前端增加维护登录、任务深链接、只读结果与重新登录流程；统一提示样式，同一维护提示去重，业务维护响应不误清控制登录。保留旧 SQLite 备份界面与能力判断。

## 升级与部署

- 普通应用仍使用 `/app/server`。分布式维护为可选部署，需要独立控制 PostgreSQL、明确的应用/认证/控制/执行权限、独立 console/gateway 和固定 Job 模板，不能仅开启一个开关就用于现有多 Pod 环境。
- 首次接入须按受控停服窗口执行认证迁移，校验当前账号后一次性导入控制权威；不会创建默认密码，也不在每次启动时同步覆盖账号。所有业务 Pod 和入口路由须统一切换。
- 使用固定镜像 digest、实例及 namespace 归属，并预建所需存储与权限。旧数据库和桶保留供核对，不提供按时间盲删、自动备份、增量备份或跨实例导入。
- 控制服务独立于业务停服，但仍依赖控制 PostgreSQL 与 Kubernetes；基础设施自身故障不保证能仅靠网页修复。认证权威回退需受控导出当前账号及撤销会话，不能直接降级到旧业务认证表。
- 部署模板为需替换占位符的示例，不含生产凭据；本次发布不会替换现有服务、改变生产 NodePort 或执行数据库恢复。

详见 [分布式备份恢复说明](https://github.com/yi-nology/rainbow_bridge/blob/v5.1.1/docs/operations/distributed-maintenance-backup.md) 与 [网页部署及权限说明](https://github.com/yi-nology/rainbow_bridge/blob/v5.1.1/deploy/kubernetes/maintenance-web/README.md)。

## 验证范围

独占 PostgreSQL、MinIO、Redis 和双业务 Pod 环境已验证网页备份、新库新桶恢复、业务双 Pod 为零时登录及任务刷新、当前密码保留、旧会话失效、数据/对象/发布与缓存核对；真实执行者中断后的继续和安全回退、对象流中断、长写超时、坏包拒绝有实施证据。前端最终构建通过32项专项及49项相关回归，最终静态已同步隔离环境，70个JS/CSS的真实HTTP响应哈希匹配。

网络截断和临时空间不足采用适配器故障测试；未将真实节点分区或真实磁盘耗尽写为已现场通过。旧 SQLite/Linux 回归按受影响范围复用，未声称本轮 Windows 全套测试通过。隔离环境按协作约定保留，正式服务未更新。

## 下载与镜像

沿用五个平台：Linux amd64/arm64、macOS amd64/arm64、Windows amd64。应用包包含嵌入前端的 app、`admin-password-reset`、`backup-restore`、`release-storage`，新增 `maintenance-backup`、`maintenance-console`、`maintenance-gateway`，以及配置、工具说明和部署模板。另提供 `frontend.zip`、`frontend.tar.gz`、`QUICKSTART.md`、`RELEASE_NOTES.md` 与 `SHA256SUMS.txt`。

应用镜像沿用 `ghcr.io/yi-nology/rainbow_bridge-app:v5.1.1`，由发布流水线构建 Linux amd64/arm64。新增维护程序位于 `/app/`，由对应部署覆盖启动命令；普通应用入口保持不变。镜像和附件以发布流水线实际完成结果为准。
