# Rainbow Bridge v5.1.3

本版完善图片上传与预览，新增资源管理单项删除，并补充代理入口可信来源的运维说明。

## 图片上传与预览

- 图片选择器增加明确的扩展名提示；配置图片上传区支持点击和拖入一张图片，复用校验与上传状态，多文件和非图片给出明确提示。
- 统一资源地址与 API 的 BasePath 规则，修复生产部署在 `/rainbow-bridge` 下上传后预览地址缺少前缀的问题；新增、编辑、列表及大图预览共用解析逻辑。
- 上传失败保留原图和草稿；预览失败可重试，范围或会话变化时拒绝旧请求回填。

## 资源删除

- 资源列表增加删除确认、引用摘要和冻结状态提示，新增 `POST /api/v1/asset/delete`。
- 删除在同一数据库写协调事务内检查范围身份、冻结状态及全部活动编辑区配置引用。被引用时返回 `409 ASSET_IN_USE`，最多展示 20 条引用摘要，不提供强制删除。
- 采用元数据软删除：原链接返回 `410 ASSET_DELETED`，重复删除幂等；新增、修改及相关导入/迁移写入拒绝重新引用已删除资源。
- 保留原始文件/MinIO 对象，不承诺立即释放存储。已发布快照使用自己的资源副本；发现遗留快照直接依赖原资源时保护性阻止删除。

## 代理来源配置

补充同 Pod 模式的真实 Secret 字段、来源合并、配置 SHA 重载及回退说明。代理 Origin 必须加入业务和 console 的可信来源列表，不关闭 CSRF，也不把内网地址加入产品默认白名单。

## 基础验证与边界

Vue 生产构建、相关 Go 基础检查、图片和删除交互 Mock、独占 SQLite 实际页面删除流程通过；WSL 验证删除原图后历史快照资源仍可下载且字节一致。图片真实上传在直连和代理入口均返回正确 MIME 和相同字节，测试范围与会话已按既有规则清理。

麒麟原生文件选择器尚未实机复核；MinIO 新删除接口未做远程实测，不把 SQLite 检查视为所有存储环境验收。未追加复杂故障或压力测试。保留的本地 QA 目录不进入发行包。

## 发布与升级

提供 Linux amd64/arm64、macOS amd64/arm64、Windows amd64 应用包及前端归档、使用说明、校验和；应用包继续包含现有维护工具。应用镜像目标为 `ghcr.io/yi-nology/rainbow_bridge-app:v5.1.3`，由 Release 流水线构建 `linux/amd64` 和 `linux/arm64`，实际产物以流水线完成结果为准。

本版不新增数据库表，沿用资源软删除字段。升级应用后才提供新删除接口；发布 tag 和镜像不会自动升级已有 Kubernetes Deployment，也不会切换业务配置版本。按现有部署方式更新版本并保留当前 Secret、存储及管理员身份。
